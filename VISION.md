## 📱 USER EXPERIENCE

### **Browser Extension Flow**
1. User clicks any link
2. Extension scans URL in background (< 100ms)
3. If safe: Page loads normally
4. If risky: Warning overlay with explanation
5. User can proceed or block with one click

### **Email Integration Flow**
1. User grants Gmail API permissions
2. Extension scans emails in background
3. Suspicious emails get flagged automatically
