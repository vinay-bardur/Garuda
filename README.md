# 🛡️ Garuda - AI-Powered Phishing Protection

**Automated browser extension that protects users from phishing attacks in real-time.**

## 🎯 Problem
- Manual phishing checkers are useless - nobody has time to copy-paste URLs
- Current tools have terrible accuracy (27/100 for obvious phishing attempts)
- Users need invisible, automated protection that just works

## 🚀 Solution
**Browser extension with AI-powered detection that:**
- Scans URLs automatically before page loads
- Uses AI for 95%+ accuracy in threat detection
- Shows instant warnings with one-click protection
- Works invisibly in the background

## 🛠️ Tech Stack
- **Frontend**: React Chrome Extension
- **Backend**: FastAPI + AWS Lambda
- **AI**: OpenAI GPT-4 + Custom ML Models
- **Database**: PostgreSQL
- **APIs**: VirusTotal, URLVoid, PhishTank
